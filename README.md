# credly-badges-widget
Widget de badges Credly com fundo transparente para GitHub Pages

## Features\n\n- Dynamic Credly API integration\n- Real-time badge fetching from Credly\n- Transparent circular badge design\n- Responsive layout\n- Hosted on GitHub Pages\n- No hardcoding - updates automatically\n\n## How to Use\n\nAccess the widget at:\n`https://aiexxplorer.github.io/credly-badges-widget/index.html`\n\nEmbed in any webpage using iframe:\n\n```html\n<iframe src="https://aiexxplorer.github.io/credly-badges-widget/" style="width: 100%; height: 600px; border: none;"></iframe>\n```
